## Fulfillment checklist

1. Confirm the file is in scope before accepting payment.
2. Save the raw input untouched.
3. Clean with a repeatable script or spreadsheet steps.
4. Check row counts before and after.
5. Export the cleaned file.
6. Write 5-10 bullet notes: changes made, questionable rows, assumptions.
7. Offer one small revision only for missed stated requirements.
