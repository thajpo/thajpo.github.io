## Overview
A work-in-progress agent for practical CSV analysis: loading messy tabular files, surfacing schema issues, generating transformations, and helping reason about data quality.

## Current Direction
- Fast local inspection of unfamiliar datasets.
- Safe transformation previews before writing outputs.
- Clear explanations of inferred columns, anomalies, and cleanup steps.
