## Overview
A personal learning project consisting of a custom interpreter written entirely in Rust from scratch to strengthen fundamental skills in Rust paradigms to overcome compiler borrow-checker issues, result-handling, and match coverage. 

## Technical Details
- Handled advanced error management resolving ignored `Result` values and implicit io handling.
- Implemented comprehensive `match` arms with static exhaustiveness checks.
- Hand-coded abstract syntax tree node compilation.
